# GTA7 — Grand City

An unofficial, original 3D open-world browser game prototype. This is a fan-made project and is not affiliated with or endorsed by Rockstar Games.

## Run locally
```bash
npm start
```
Open http://localhost:3000

## Controls
- WASD / Arrow keys: walk or drive
- E: enter / exit a nearby car
- Shift: sprint
- Space: handbrake while driving
- Drag mouse: rotate camera
- Escape: pause / return to title

The city, vehicles, characters, and gameplay are original procedural creations. Three.js is loaded from jsDelivr at runtime.
